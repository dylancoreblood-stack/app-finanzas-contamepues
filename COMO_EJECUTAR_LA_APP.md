## 💻 ¿Cómo ejecutarla en tu computador o en Expo Go?

Abre una terminal en esta carpeta (`/Users/DylanRamirez/Downloads/Gemini Dylan/App finanzas contamepues`) y ejecuta:

```bash
export PATH="/usr/local/bin:$PATH"
npm start
```

- Presiona `w` para abrir la versión Web adaptable en tu navegador.
- O escanea el código QR con tu celular usando la app **Expo Go** (iOS / Android).

## 🌐 Despliegue en Vercel (1 Clic)

1. Ingresa a **[vercel.com/new](https://vercel.com/new)**.
2. Selecciona el repositorio **`dylancoreblood-stack/app-finanzas-contamepues`**.
3. En el Framework Preset selecciona **Other** (o Expo).
4. El comando de build configurado es: `npm run build:web` y el Output Directory es `dist`.
5. Haz clic en **Deploy**.
6. En Vercel Settings > Domains puedes agregar un dominio o subdominio de tu hermano como:
   `finanzas.contamepues.com` o `app.contamepues.com`.
